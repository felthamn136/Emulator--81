Our Commitment

We are committed to fostering an open, welcoming, and respectful community for everyone, regardless of experience level, background, identity, or technical expertise.

Our goal is to create an environment where contributors can collaborate, learn, share ideas, and help improve the project in a constructive and supportive way.

Expected Behaviour

We encourage all community members to:

Be respectful and courteous to others.
Provide constructive feedback and criticism.
Assume good intentions when interacting with contributors.
Help create a positive and inclusive environment.
Be patient with newcomers and those learning new skills.
Focus discussions on the project and its improvement.
Respect differing viewpoints and experiences.
Unacceptable Behaviour

The following behaviours are not acceptable within this project:

Harassment, discrimination, or hateful conduct.
Personal attacks, insults, or abusive language.
Trolling, inflammatory comments, or deliberate disruption.
Publishing private information about others without permission.
Repeatedly dismissing or belittling the contributions of others.
Any behaviour that would reasonably be considered inappropriate in a professional environment.
Contributions

All contributions, including issues, pull requests, discussions, documentation, and code reviews, should be conducted in a respectful and collaborative manner.

Contributors are encouraged to:

Submit clear and well-documented changes.
Report bugs with sufficient detail to reproduce them.
Suggest improvements constructively.
Accept feedback gracefully and professionally.
Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Maintainers reserve the right to edit, remove, or reject comments, issues, pull requests, or other contributions that do not align with these guidelines.

In serious or repeated cases of misconduct, maintainers may temporarily or permanently restrict participation in the project.

Reporting Issues

If you experience or witness behaviour that violates this Code of Conduct, please contact the project maintainer.

Reports will be reviewed fairly and, where possible, handled confidentially.

Scope

This Code of Conduct applies to all project spaces, including:

GitHub Issues
Pull Requests
Discussions
Documentation contributions
Project-related social media and community interactions
